## 1) What is Agentic AI?

**Traditional LLM App**

You prompt → model replies.
One shot. No memory. No decisions. Like a smart calculator.

**Agentic AI**

LLM decides what to do next, not just answer you.
It can…

| Ability      | Meaning (Simple)         | Analogy                         |
| ------------ | ------------------------ | ------------------------------- |
| Plan         | Break task into steps    | You plan cooking before cooking |
| Use tools    | Call APIs, DB, search    | You use phone/maps/web          |
| Remember     | Short + long-term memory | You remember conversation       |
| Self-Reflect | Improve answers          | Writer edits draft              |
| Loop         | Retry / iterate          | Keep debugging until runs       |

**💡 Agent = autonomous LLM + memory + tools + reasoning loop**


## 2) Why LangGraph?

LangGraph = framework for AI agents as graphs

| Concept           | Meaning                                      |
| ----------------- | ---------------------------------------------|
| Node              | An action (step) (e.g., call LLM, call tool) |
| Edge              | Path from step A → step B                    |
| State             | Shared memory for agent thinking             |
| Conditional Edges | Decide next step                             |
| Cycles            | Feedback loops (retry, reflect)              |
| Persistence       | Save state for later (chat memory)           |

Think of LangGraph like workflow engine for LLM brains.
Not just prompts — LLM programs.

## 5) Your First LangGraph Agent

Goal: Agent asks “What task do you want to do?” → Uses GPT to respond.

`hello_agent.py`:

```python
from langgraph.graph import StateGraph
from langchain_openai import ChatOpenAI

# 1. State (shared memory shape)
class State(dict):
    pass

# 2. Model
llm = ChatOpenAI(model="gpt-4.1")

# 3. Node = step
def agent_node(state: State):
    user_input = state["input"]
    response = llm.invoke(user_input)
    return {"output": response.content}

# 4. Build graph
graph = StateGraph(State)
graph.add_node("agent", agent_node)
graph.set_entry_point("agent")

# 5. Compile
app = graph.compile()

# Run it
result = app.invoke({"input": "Explain AI like I'm 10"})
print(result["output"])
```
You just built a single-node agent workflow. This is the "Hello World" of LangGraph.
