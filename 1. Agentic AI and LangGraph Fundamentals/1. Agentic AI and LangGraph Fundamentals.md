## 1) What is Agentic AI?

**Traditional LLM App**

You prompt → model replies.
One shot. No memory. No decisions. Like a smart calculator.

**Agentic AI**

LLM decides what to do next, not just answer you.
It can…

| Ability      | Meaning (Simple)         | Analogy                         |
| ------------ | ------------------------ | ------------------------------- |
| Plan         | Break task into steps    | You plan cooking before cooking |
| Use tools    | Call APIs, DB, search    | You use phone/maps/web          |
| Remember     | Short + long-term memory | You remember conversation       |
| Self-Reflect | Improve answers          | Writer edits draft              |
| Loop         | Retry / iterate          | Keep debugging until runs       |

**💡 Agent = autonomous LLM + memory + tools + reasoning loop**


## 2) Why LangGraph?

LangGraph = framework for AI agents as graphs

### What is a Workflow?
A **workflow** is a sequence of connected steps that accomplish a task. Think of it like a flowchart or a recipe:
- Each step does something specific
- Steps are connected in a logical order
- Data flows from one step to the next
- You can have decisions, loops, and branches

**Example**: Customer support workflow
1. Receive question → 2. Search knowledge base → 3. If found: answer, else: escalate to human

### Core Concepts

| Concept           | Meaning                                      | Think of it as...                |
| ----------------- | -------------------------------------------- | -------------------------------- |
| Workflow          | The entire flow from start to finish         | A recipe or process              |
| Node              | A function that does work in the graph       | A step in the recipe             |
| Step              | When a node executes (runtime)               | Actually performing that step    |
| Action            | What an agent does (tool use, API calls)     | The actual work (chop, stir, etc)|
| Edge              | Connection from one node to another          | "Then do this next"              |
| State             | Shared memory that passes between nodes      | The ingredients bowl             |
| Conditional Edges | Decide which node to go to next              | "If salty, add sugar"            |
| Cycles            | Loops that allow retry/refinement            | "Taste and adjust"               |
| Persistence       | Save state for later (chat memory)           | Save recipe progress             |

### Key Distinctions
- **Node vs Step**: A node is the *definition* of work; a step is the *execution* of that node
- **Node vs Action**: In simple cases, a node just calls an LLM. In agentic systems, a node performs *actions* like using tools, searching databases, or calling external APIs
- **Workflow vs Agent**: A workflow is the structure; an agent is an AI system that can make decisions within that workflow

### How Actions Are Selected (Agentic Behavior)
In true agentic systems, here's what happens during a step:

1. **Node defines candidate actions** - A node may have access to multiple tools/actions
   - Example: `[search_web, query_database, call_api, calculate]`

2. **Agent decides during execution** - When the step runs, the LLM:
   - Analyzes the current state
   - Reasons about which action(s) are most suitable
   - Selects one or more actions to perform

3. **Action(s) get executed** - The chosen action(s) run and update the state

**Example**: Research Agent Node
```
Available actions: [search_web, read_pdf, query_database]
User asks: "What's the latest on quantum computing?"
→ Agent selects: search_web (most suitable for latest info)
```

**💡 This is what makes it "agentic"** - the AI decides *what to do*, not just *what to say*.

Think of LangGraph like a workflow engine for LLM brains.
Not just prompts — LLM programs.

## 5) Your First LangGraph Agent

Goal: Agent asks “What task do you want to do?” → Uses GPT to respond.

`hello_agent.py`:

```python
from langgraph.graph import StateGraph
from langchain_openai import ChatOpenAI

# 1. State (shared memory shape)
class State(dict):
    pass

# 2. Model
llm = ChatOpenAI(model="gpt-4.1")

# 3. Node = step
def agent_node(state: State):
    user_input = state["input"]
    response = llm.invoke(user_input)
    return {"output": response.content}

# 4. Build graph
graph = StateGraph(State)
graph.add_node("agent", agent_node)
graph.set_entry_point("agent")

# 5. Compile
app = graph.compile()

# Run it
result = app.invoke({"input": "Explain AI like I'm 10"})
print(result["output"])
```
You just built a single-node agent workflow. This is the "Hello World" of LangGraph.
